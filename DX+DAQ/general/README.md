# General

DX+ DAQ is where you build the data acquisition table for a session — adding devices, configuring per-stream processors, and choosing where the data goes. Once the table is set up, you submit it to begin acquiring, recording, and/or transmitting data.

This section covers the parts of DAQ that aren't tied to a specific device or processor:

* [**Ribbon**](ribbon.md) — the top toolbar actions: add / remove devices, manage setup files, and submit the table.
* [**Devices / Sources Panel**](devices-panel.md) — the list of devices in the current setup and the controls for inspecting, editing, and removing them.
* [**Table Operations**](table-operations.md) — selecting streams, editing the DAQ table, and applying processor settings across multiple streams at once.
